About the data

Items come from three sources: APT's Comprehensive Index (subject headings, and items from 2005 to 2007), JSTOR records via Crossref (1969 to 2004), and the tables of contents APT posts for 2008 to 2026. Practice Point numbers and PDFs are from APT's Practice Points page. Issues 25.1/2 (1993) and 44.4 (2013) are missing, and the 1969 to 1972 issues are only partly covered.

Committee and discipline tags were suggested by a language model from each item's title and APT index headings, using a written rubric. Nobody read the articles, and the tags have not yet been reviewed by the APT Publications Committee. Discipline describes each piece's main lens, not its authors' training. Corrections are welcome as GitHub issues.
